# MovieMood 🎬

MovieMood is a full-stack movie recommendation web application that helps users discover movies using intelligent recommendation logic powered by the TMDB API.

## Features

- Smart movie recommendation engine
- Genre-based recommendations
- Popularity and rating prioritization
- Personal watchlist management
- Star rating system
- Responsive UI for desktop and mobile
- LocalStorage-based authentication
- TMDB API integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Deployment
- Railway

## Recommendation Engine

MovieMood uses a layered recommendation system:

1. Genre similarity matching
2. Popularity-based ranking
3. Rating prioritization
4. Fallback recommendation logic

This improves recommendation quality and user personalization.
